# Open Beta

Lorist is currently in an open beta phase. This means that it’s feature–complete, but yet to be widely tested with real usage across a diverse range of folks.

## Known issues

Known issues are being tracked in <a href="https://github.com/scott-riley/lorist-writer">GitHub</a>.

## It should still work

If you encounter something that feels really busted, please do raise an issue and don’t put it down to ‘beta roughness’. Everything in Lorist should _work_. It might not work _amazingly_, but if you’re not able to do something you feel you should, it’s probably a bug.

## Some things might break

There might be some UI jank here and there, and some areas might not be as polished as they could be. There’s every chance that if you really push things you can get the product to do some pretty hilarious stuff.

## Spotted a bug?

If you’ve found a bit of jank (and double–checked your <a href="/technical-bits/browser-support.html">browser supports</a> the necessary features) then head on over to the <a href="https://github.com/scott-riley/lorist-writer/issues">Issues section of the GitHub repo</a> to report it.

If you can include screenshots/screen recordings, clear descriptions of your issue, and what you _think_ should happen that doesn’t then you’ll help get things fixed that much quicker.

Thanks for taking the time to give Lorist a spin!
