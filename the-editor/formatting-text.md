# Formatting text

Formatting text in Lorist can be done in one of three ways:

1. Wrapping text in markdown syntax
2. Selecting text and hitting a keyboard shortcut
3. Selecting text and using the formatting menu popover

Here’s some common formatting options, with their corresponding Markdown and keyboard shortcuts.

::: info {no-title}
`Mod` = `Cmd` on macOS, `Ctrl` on Windows/Linux.
:::

| Format        | Markdown     | Keyboard shortcut |
| ------------- | ------------ | ----------------- |
| Bold          | `**text**`   | `Mod-B`           |
| Italic        | `*text*`     | `Mod-I`           |
| Strikethrough | `~~text~~`   | `Mod-Shift-S`     |
| Inline code   | `` `code` `` | `Mod-E`           |

## Adding Links

The easiest way to turn text into a link is to copy the link you want to use, select the words you want to turn into a link, and hit paste. This will automatically format the selected text as a link.

You can edit or remove a URL associated with any link text using the link icon in the formatting popover menu.
