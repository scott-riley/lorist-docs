# Markdown and shortcuts

While Lorist is Markdown–based, you might prefer using good old–fashioned keyboard shortcuts to format your text. Below you’ll find a reference of available formatting options alongside its corresponding Markdown syntax and keyboard shortcut.

::: info {no-title}
`Mod` = `Cmd` on macOS, `Ctrl` on Windows/Linux.
:::

## App shortcuts

| Action                  | Shortcut      |
| ----------------------- | ------------- |
| Toggle Focus Mode       | `Mod-/`       |
| Expand/collapse Sidebar | `Mod-Shift-E` |
| Open ‘go to…’ panel     | `Mod-K`       |

## Headings

| Block     | Markdown | Keyboard shortcut |
| --------- | -------- | ----------------- |
| Heading 1 | `# `     | `Mod-Alt-1`       |
| Heading 2 | `## `    | `Mod-Alt-2`       |
| Heading 3 | `### `   | `Mod-Alt-3`       |

## Text formatting (marks)

| Format        | Markdown     | Keyboard shortcut |
| ------------- | ------------ | ----------------- |
| Bold          | `**text**`   | `Mod-B`           |
| Italic        | `*text*`     | `Mod-I`           |
| Strikethrough | `~~text~~`   | `Mod-Shift-S`     |
| Inline code   | `` `code` `` | `Mod-E`           |

## Lists

| Block                 | Markdown   | Keyboard shortcut            |
| --------------------- | ---------- | ---------------------------- |
| Bullet list           | `- item`   | `Mod-Shift-8`                |
| Ordered list          | `1. item`  | `Mod-Shift-7`                |
| Task list (unchecked) | `[ ] item` | None (press space after `]`) |
| Task list (checked)   | `[x] item` | None (press space after `]`) |

## Blocks

| Block           | Markdown     | Keyboard shortcut |
| --------------- | ------------ | ----------------- |
| Blockquote      | `> text`     | `Mod-Shift-B`     |
| Code block      | `` `code` `` | `Mod-Alt-C`       |
| Horizontal rule | `---`        | None              |
| Hard break      | None         | `Shift-Enter`     |

## History

| Action | Keyboard shortcut       |
| ------ | ----------------------- |
| Undo   | `Mod-Z`                 |
| Redo   | `Mod-Shift-Z` / `Mod-Y` |

::: info {no-title}
`Mod` = `Cmd` on macOS, `Ctrl` on Windows/Linux.
:::
